## ⚡ About Me

I'm a Senior Software Developer (5+ years) who spends most of the day thinking about how software can **remember, reason, and act** — not just respond. I run an independent studio building AI agents, RAG pipelines, and LLM-driven workflows, on top of a full-stack foundation of Spring Boot, Angular, Next.js, and PostgreSQL, deployed on Azure/AWS.

```yaml
santosh:
  focus:
    - Autonomous AI Agents (planning, tool-use, multi-agent orchestration)
    - Agent Memory Systems (long-term, episodic, retrieval-augmented recall)
    - RAG Pipelines (chunking, embeddings, hybrid search, re-ranking)
    - LLM Workflow Engineering (routing, fallback, prompt/context design)
    - QLoRA fine-tuning for domain-specific models
  stack:
    backend:  [Spring Boot, PostgreSQL, Python]
    frontend: [Angular, Next.js, TypeScript]
    ai_ml:    [LLMs, RAG, LangChain-style orchestration, Ollama, QLoRA]
    cloud:    [Azure, AWS]
  currently: "Building autonomous, memory-aware AI systems end to end"
```

## 🧠 What I'm Building — AI, Agents & Memory

<table>
<tr>
<td width="50%" valign="top">

### 🤖 AI Agents & Orchestration
Designing agents that don't just chat — they plan, call tools, self-correct, and coordinate with other agents. Working across single-agent workflows and multi-agent control planes that route tasks across a suite of tools and services.

</td>
<td width="50%" valign="top">

### 🧩 Agent Memory
Exploring how agents retain context across sessions — long-term memory stores, retrieval-augmented recall, and structured knowledge that lets an agent "know" what it's done before instead of starting from zero every time.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📚 RAG Pipelines
Building retrieval pipelines end to end: chunking strategies, embedding generation, hybrid/vector search, and re-ranking — tuned for domain-specific corpora rather than generic Q&A.

</td>
<td width="50%" valign="top">

### 🛠️ LLM Workflow Engineering
Multi-provider LLM routing with failover, local model serving with Ollama, and QLoRA fine-tuning to adapt models to specific engineering domains without full retraining.

</td>
</tr>
</table>
